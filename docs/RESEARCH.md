## 技术栈候选（供 C 定稿，候选身份，非已定方案）

> 约束：一期 12-06 预赛截止（时间紧）；方向「轻量化」；评委打开链接即可演示（免安装）；
> 系统数据必须模拟（E23）；建模素材走公开信息 + 自建粗模 + 组委会基准场景保底（D005）。
> 以下为候选清单；**2026-11-25 已由 C 定稿（D006）**：采纳「Three.js 首选」路线 + 原生 JS + 规则兜底。

### A. 3D 渲染引擎（核心）

| 方案 | 特点 | 本项目适配度 |
| --- | --- | --- |
| Three.js（+ React Three Fiber） | 生态最大、教程多、轻量、glTF 支持成熟；R3F 用 React 声明式写 3D | **首选**：团队有前端基础，上手快，体积小 |
| MapLibre GL JS | 室内平面图 + 楼层切换成熟，2.5D；不是真 3D 自由视角 | 备选：若走「室内地图导览」而非「自由 3D 漫游」更省 |
| CesiumJS | 3D Tiles、大场景 GIS 强；偏重、偏地理坐标 | 偏重，商场室内导览用不上其 GIS 能力 |
| Babylon.js | 功能全、自带编辑器；体积与学习曲线更大 | 备选 |
| PlayCanvas | 在线编辑器、WebGL 优化好 | 备选 |

### B. 建模与资源

- 建模工具：**Blender**（免费，导出 glTF/GLB，适合自建粗模）。
- 资源格式：**glTF/GLB + Draco 压缩**（体积小、加载快，移动端友好）。
- 场景来源：组委会金水商圈基准场景（保底）→ 自带正弘城场景（加分，需自建或采集）。

### C. 数据联动 + AI 决策闭环（赛道 A 硬要求，O05 相关）

- 模拟数据：**纯前端生成**（最轻，符合「数据必须模拟」E23）或轻量后端。
- 后端/托管：可选本项目可用云服务（云数据库 / 文件存储 / 免密钥大模型调用），或纯静态无后端。
- AI 建议：调大模型接口，规则引擎兜底（保证演示不翻车）。

### D. 部署

- 静态托管 / 发布为在线链接（评委浏览器打开即演示），符合「免安装」。
