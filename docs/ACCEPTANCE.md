## 1. 什么时候跑哪些行

| 触发条件 | 跑哪些行 |
| --- | --- |
| 局部逻辑、页面或样式改动 | 只跑受影响的不变量与关联流程 |
| 工程初始化 | 建立类型检查、lint、业务测试与构建的实际入口，并接入 CI |
| 首次完整上线，或影响多个核心流程 | 全表适用行 + 桌面 + 实际设备 |
| 实际部署 | 生产构建、依赖、持久化、重启后可读等部署专用检查 |
