二、本次新手段的详细操作（可复用）

手法 A：浏览器自动化抓百度图片 最有效

百度图片的真实图片地址写在 <img src> 里，是 JS 动态生成的，curl 抓源码拿不到。必须用能执行 JS 的浏览器（本次用 agent-browser），滚动加载后用 JS 把所有 img.src 提取出来。

# 1. 打开搜索页（关键词 URL 编码）
agent-browser open "https://image.baidu.com/search/index?tn=baiduimage&word=郑州正弘城 楼层品牌全攻略"

# 2. 滚动加载更多（重复 2-3 次）
agent-browser eval "window.scrollTo(0,document.body.scrollHeight)"

# 3. JS 提取所有真实图片 URL
agent-browser eval "(()=>{const r=[];document.querySelectorAll('img').forEach(i=>{
  const s=i.src;
  if(s&&s.startsWith('https://img')&&s.includes('/it/u='))
    r.push(s.split('?')[0]+'?w=500')
});return JSON.stringify([...new Set(r)])})()"

# 4. 把 URL 列表交给脚本批量下载 → 拼总览 → 人工甄别

关键提醒：百度图片按关键词返回的结果混杂严重（商品图、其他商场、文字截图、无关实景）。必须下载后拼总览人工甄别，不能整批入库——本次 500+ 张里真正可用的只有 47 张。这与之前搜狗/Trip.com 的教训一致。

本次用过的 4 组关键词（可继续扩展）：

  • 郑州正弘城 店铺门头 → GUCCI/OMEGA 专柜、霸王茶姬、九田家烤肉、中古名店
  • 郑州正弘城 楼层品牌全攻略 → 楼层品牌全览图、文字分布图
  • 正弘城 等位 排队 → 多为菜品图，收效小
  • 正弘城 中庭 扶梯 内部 → 大量中庭环形挑空实景（19 张）

可继续尝试的关键词：正弘城 B1 食光里、正弘城 7F 犇小喜、正弘城 西西弗书店、正弘城 导览图 高清、正弘城 周大福、正弘城 二次元街区。

手法 B：高德 / 百度地图 POI 图片 API 需申请 Key

高德开放平台「搜索 POI 2.0」接口，设置 show_fields=photos 后会返回每个商家的 photos.url（图片下载链接）和 photos.title。可先用多边形区域搜索圈定正弘城范围，再批量拉所有餐饮/店铺 POI 的门头图。

# 高德 Web 服务 API（需个人开发者 Key）
https://restapi.amap.com/v5/place/polygon?key=YOUR_KEY&polygon=边界坐标&show_fields=photos&types=餐饮

# 返回字段：poi.name / poi.photos[].url / poi.photos[].title

优点：按店铺名精确取图、可批量、数据干净。缺点：需注册开发者申请 Key（个人有每日配额），免费额度拉一个商场足够。网页端的 amap.com/service/poiInfo 接口已失效（返回首页），走官方 Key 是正路。

手法 C：公众号探店文采集 质量最高

垂直类公众号的门头测评文质量最高——此前「餐饮老板内参」51 家测评抓到 17 张带店名的真实门头。可用微信文章搜索（mp.weixin.qq.com/s?...）抓取，图在 mmbiz.qpic.cn，带 Referer 可直接下载。

找文渠道：普通搜索引擎搜「正弘城 门头 site:mp.weixin.qq.com」比搜狗微信好用（搜狗微信本次返回空）。本地商业号「郑州商业观察」是重要来源——本次百度图里 GUCCI/OMEGA 专柜图就带它的水印。
