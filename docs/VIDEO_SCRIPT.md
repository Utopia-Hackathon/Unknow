# 3 分钟演示视频分镜脚本

版本：v0.1（保守版成稿 2026-11-27）
时长上限：**3:00**（规程硬性要求，超时直接违规）
依据：`docs/ACCEPTANCE.md` A01–A11；`docs/PAIN_POINT.md`；`docs/METRICS_DEF.md`

> **本脚本纪律**：每个镜头对应一条验收项。**没有在冻结版本上通过的功能，不进成片**。

## 三、录制前检查清单

- [ ] 浏览器窗口 1920×1080，录屏帧率 30fps，`dist` 为 12-03 冻结版本。
- [ ] 楼层选择器只有 6F / 7F / 8F，无空白按钮（A11）。
- [ ] 搜索框可输入中文，输入法状态提前切好。
- [ ] 每个镜头录 2 遍，留一条备份；单镜超时应剪短而非加快旁白语速。
- [ ] 旁白录音先试录 10 秒确认底噪，再按镜号分段录，方便替换。
- [ ] 成片导出后核对时长 ≤ 3:00，再核对每个镜头能在交付版本上复现。

## 四、不得入片的内容（红线）

- ❌ 任何未在冻结版本上通过验收的功能（含「未来会做」的镜头）。
- ❌ 真实顾客的人脸、手机号、排队号，或任何可识别个人信息。
- ❌ 「已接入商场系统」「与正弘城合作」之类表述。
- ❌ 无来源的门头照或宣称「本队实拍」的第三方图片（见 `RESEARCH_LOG.md` §二）。
- ❌ 未经样本量支撑的流失率百分数（A07 硬判据）。
