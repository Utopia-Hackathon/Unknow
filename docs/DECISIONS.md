### D010 主指标定为「顾客流失率」，关闭 Q003

- 内容：
  1. 主指标**唯一**：**顾客流失率 `lossRate`**。公式 `lossRate = 流失人数 / (入座人数 + 流失人数)`，分母为**已产生结局的顾客数**，窗口末仍在排队者按右删失剔除并单独报 `censored`。
  2. 统计窗口 **120 分钟**；样本量 `n < 30` 返回「样本不足」，**不得返回 0 或伪数值**。
  3. 前后对比采用**配对比较**：同 `seed`、同到达序列、同桌位配置，唯一变量为「FIFO」→「桌型匹配 + 过号回捞」。
  4. 过号率、平均等位时长、桌位空置占比、回捞成功率**仅作辅助展示**，不得称主指标、不得取代流失率作结论。
  5. 指标页必须同时显示：公式、`n` 值与删失人数、模拟数据标识；措辞限定为「在这组模拟参数下」。
  6. 完整口径见 `docs/METRICS_DEF.md`（含算例），该文件为 D-02 的实现契约。
