## 一、录前 5 分钟设置

1. 用 **12-03 冻结的 `dist`** 起静态服务（`npx vite preview` 或等价静态服务），**不要用 `npm run dev`**。
2. 浏览器窗口 **1920×1080**，录屏 **30fps**；成片硬上限 3:00，单镜超时应剪短，不加快语速。
3. URL **不要带 `?textures=dryrun`**——dry-run 会显示醒目横幅「当前显示的是第三方媒体参考素材，非交付贴图」，不能入片。
4. 中文输入法提前切好；`#search-input` 需可直接输入中文并回车。
5. 首屏数据徽章当前显示「点位：占位示意值（待 B 现场核实）」（`data/stores.json` 未进 main）。这是真实状态，不要隐藏，S4 旁白靠它成立。
6. 每个镜头录 2 遍留备份；旁白按镜号分段录，便于替换。

## 三、录前需枯木拍板的一处

S9 旁白原文「数据全部模拟，来源与边界写在我们提交的材料里」。但 `RESEARCH_LOG.md` 记有本队 11-23/24 实地调研、8 张门头实拍与楼层索引牌——「全部模拟」字面过强，评委追问时容易被抓住。本卡**不改脚本**，录前请二选一：

- A：照脚本念原文（若认定门店名/楼层来源属「示意」，指标属「模拟」，口径可自洽）；
- B：改为「经营指标为模拟数据，门店名称与楼层来自公开信息和本队实拍」。

拍板结果由 A 写回 `VIDEO_SCRIPT.md` S9 行后再录，不在此卡内定案。
